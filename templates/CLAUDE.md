## Сервисы

| Папка | Что это | Стек | Порт | Адрес |
|---|---|---|---|---|
| `api` | API, владелец базы и схемы | Hono, Prisma, Postgres | 4000 | https://api.example.ru |

## Команды

```
docker compose up -d db                    # локальная база для разработки
pnpm dev                                   # разработка
pnpm build                                 # перед каждым коммитом — без ошибок
npx prisma migrate dev --name <что_меняем> # единственный способ менять схему
```
