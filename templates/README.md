# Заготовки проекта

Без подсказки нейросеть делает эти файлы неправильно или не делает вовсе. Скопируй в свой проект то, что нужно: `api/` и `admin/` есть почти всегда, `site/` — только если нужен публичный сайт с поиском.

| Файл | Что без него идёт не так |
|---|---|
| `CLAUDE.md` | ассистент не знает масштаб проекта и строит корпорацию |
| `docker-compose.yml` | разработка идёт в боевой базе; хук из `hooks/` не даст мигрировать не в локальную |
| `Dockerfile` | образ в один этап, от root, с исходниками и dev-зависимостями |
| `.dockerignore` | `.env` с ключами уезжает в образ |
| `.npmrc` | из России `pnpm install` падает или висит |
| `pnpm-workspace.yaml` | pnpm не даёт Prisma скачать движки, сборка падает на `prisma generate` |
| `.env.example` | непонятно, какие переменные нужны; сервис падает из-за необязательного ключа |
| `scripts/check-architecture.mjs` | правила из `AGENTS.md` остаются словами: через месяц логика в роутах и компоненты по 900 строк |

## Подключить сторожа

В `package.json` каждого сервиса:

```json
"scripts": {
  "check:arch": "node scripts/check-architecture.mjs",
  "check": "pnpm build && pnpm check:arch"
}
```

`pnpm check` перед коммитом. Ошибка — коммит не проходит. Что именно проверяется — в начале самого скрипта и в `AGENTS.md`, раздел 4.

В `api/` пакет `prisma` держи в `dependencies`, а не в `devDependencies`: образ ставит только рабочие зависимости, а `prisma migrate deploy` нужен при старте.
