# Изменения

Версия правил стоит в начале `project/AGENTS.md`. Чтобы обновить правила в своём проекте, дай нейросети сообщение из README, раздел «Обновить правила».

## 2026-11-24 — первая публичная версия

Правила прошли три независимых ревью. Что в них есть:

- **Правила для нейросети:** масштаб маленького продукта, 27 болезней вайбкодерских проектов с лекарствами, архитектура «бэкенд, фронт, база», стек, общие правила кода, база и миграции, секреты, 152-ФЗ, деплой в Dokploy, сеть из России.
- **Правила каждого сервиса** в его `AGENTS.md`: `api/` (бэкенд), `api/prisma/` (база), `admin/` (SPA), `site/` (SSR). Рядом — `CLAUDE.md` из одной строки для Claude Code.
- **Хук Claude Code `guard-db`:**
  - Prisma — по белому списку;
  - адреса базы — как у Prisma: окружение, профиль, `.env`, все поля `datasource`, `prisma.config.ts`, сверка с `docker-compose.yml`;
  - блокирует ручной SQL, туннели к базе, `--no-verify`, смену `core.hooksPath`;
  - заглядывает в запускаемые скрипты и npm-скрипты.
- **Сторожа устройства кода** для API и фронта: импорты с алиасами и без расширений, запросы не из своего слоя, файлы длиннее 600 строк.
- **Git-хук перед коммитом:** ищет секреты и `.env`, запускает сторожа. Страховка — GitHub Actions.
- **Заготовки:** Dockerfile на Node 24 с проверкой здоровья, `.dockerignore`, `.env.example`, `.npmrc` с зеркалом, `pnpm-workspace.yaml` с задержкой для свежих пакетов, `docker-compose.yml` с локальной базой, `.gitignore`.
- **Сервер:** установка Dokploy, панель только со своих адресов, SSH по ключу, бэкапы, которые не стереть с сервера, наблюдение за диском и доступностью, проверки перед запуском.
